# Nexo Digital — Site institucional

Site institucional da Nexo Digital, publicado via GitHub Pages.

## Estrutura

- `index.html` — página única com todas as seções
- `assets/css/style.css` — estilos
- `assets/js/main.js` — menu, animações e formulário para WhatsApp

## Seções

1. Hero com proposta de valor
2. Modelos de página (6 opções, cada uma com CTA de WhatsApp)
3. Serviços (sites, Google/presença local, campanhas)
4. Anúncios no Google (como funciona, passo a passo)
5. Melhorias avançadas para pequenas empresas
6. Investimento (Essencial · Base Digital Completa R$ 6.000 · Evolução contínua)
7. Método de trabalho
8. Confiança
9. FAQ
10. Contato (formulário que envia para o WhatsApp)
